## ADDED Requirements

### Requirement: UI/UX improvements without behavioral changes

This change introduces visual and UX improvements that do not alter the functional behavior of the application. No new capabilities or modified requirements are introduced. All changes are cosmetic or UX-only:

- Favicon replacement (visual, no behavioral change)
- Footer component (informational, no behavioral change)
- Scroll-to-top on route change (navigation UX, no spec-level requirement)
- Lazy loading on images (performance optimization, no behavioral change)
- 404 page (user feedback for invalid routes, no spec-level requirement)
